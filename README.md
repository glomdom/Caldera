# Caldera

Yet another vulkan bindings generator for C#. But this time, better.

## Goal

Modern C# bindings for vulkan, for use in game engines, rendering projects, etc.

## Status

Currently, Caldera can generate ABI-compatible structs from the entire vulkan registry (tested on version `1.4.350.0`), as well as enums, bitflags, and types.
Alias resolution is also implemented.
